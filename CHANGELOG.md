# Changelog

## 0.1.0

- V4 lossless XOR/byte-plane/zlib file compression.
- Whole-folder bundles with tokenizer/config inclusion and empty-directory preservation.
- Pack, unpack, verify and compare CLI commands.
- SHA-256 integrity and optional decoded-byte limits.
- Atomic file publication; staged folder restoration; no-overwrite defaults.
- Path validation and symlink rejection.
- Automated tests and configured GitHub Actions workflow.
- TinyLlama 1.1B reference benchmark: 26.45% checkpoint storage reduction, exact reconstruction. Ratio is not guaranteed for other models.

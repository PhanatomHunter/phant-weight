# Contributing

Install with `python -m pip install -e '.[test]'` and run `python -m pytest -q`.
Add regression tests for every format or validation change. Retain LCV1 decoding compatibility or introduce a new magic/version. Do not change archive framing silently.

For performance claims, record exact checkpoint revision, hardware/runtime environment, archive sizes, elapsed times and independent reconstruction verification. Do not relabel compression as intelligence extraction or imply that one model's ratio generalizes.
